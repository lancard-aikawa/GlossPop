    GlossPop

    Markdown やテキストを表示して、知らない言葉を選択するだけで辞書に登録できるビューアです。

    1. 左のパネルからファイルを開くか、テキストを貼り付けて 表示 を押します。
    2. 本文中の語句を選択すると ＋ 辞書に登録 ボタンが出ます。
    3. ダイアログで ✨ AI で下書き を押すと Claude が定義・カテゴリ案を作ります。
    4. 保存すると、以後その語は本文中で自動的にリンクになり、ホバーで吹き出しが出ます。

    Claude Code 側からは /gloss-add スキルでも登録できます。
