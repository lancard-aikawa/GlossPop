# 誰に解説してもらうか — ペルソナ（口調と顔）のレシピ

GlossPop は、辞書の**要約と本文を AI に下書きさせる**。そのときの
**書きぶりを一行で指定できる**（⚙ の **AI** タブ →「文体（口調）」）。

```
講談・軍記物のような語り口で。歯切れよく、体言止めを混ぜる。
```

これだけで、以後の下書きがその調子になる。**設定は作品ごとに置ける**ので、
『吾輩は猫である』のフォルダでは猫が、社内資料のフォルダでは事務方が解説する、
という使い分けができる。

**顔も置ける。** 文体と同じ場所（`.glosspop/`）に `persona.png` を置くと、
**吹き出しと用語ページにその語り手の顔が丸く出る**。同じ表記が複数の辞書にあって
吹き出しが並ぶときは、**行ごとにその辞書の顔**が出る。

設定の場所と優先順は [MANUAL.md の「文体（口調）」](../MANUAL.md#文体口調)にある。
ここには**何を書くと面白いか**だけを置く。

## 何が変わるか

同じ用語に、同じ AI が、指示だけ変えて書いたもの（**イメージ**。実際の文面は
モデルと本文で変わる）。

| 指定 | 要約の調子 |
| --- | --- |
| なし | 主人公の友人。川に落ちた子どもを助けようとして行方不明になる。 |
| 猫が語る | 主人公の友人だそうである。川へ落ちた子どもを助けに行ったきり戻らぬというから、人間というものはよくよく物好きにできている。 |
| 講談調 | 主人公が友。川に落ちし童を救わんとして、そのまま帰らず。 |

**変わるのは書きぶりだけで、事実は変えさせない。**

## 効くところ・効かないところ

| 効く | 効かない（指定しても崩れない） |
| --- | --- |
| 要約（吹き出しに出る 1〜2 文）・本文・使用例 | 用語名・読み・別名 |
| 関係の一言（「級友」「宿敵」など） | カテゴリ・サブカテゴリ・タグ |
| | 関係の相手・上下・判明位置 |

範囲を切ってあるのは趣味ではない。**用語名が文書中の表記とずれると本文でリンクに
ならない**ので、口調に合わせて名前まで崩されると「なぜか候補が 1 つも出てこない」
という壊れ方をする。理由は
[design-notes.md](design-notes.md#文体口調は指定できるただし効くのは人が読む文章だけ)。

## 青空文庫で試す

著作権の切れた作品なら、落としてそのまま読める。**zip を展開して `.txt` を置くだけ**
でよく、文字コード（Shift_JIS）もルビ `《》` も冒頭の説明ブロックも、読み込みのときに
GlossPop が落とす。

1. 図書カードから **テキストファイル（ルビあり）** の zip を落として展開する
2. `.txt` を好きなフォルダに置く（**変換は要らない**）
3. ビューアの **📁 フォルダを選ぶ…** でそのフォルダを開く
4. ⚙ → **AI** → 文体（口調）→ **📁 いま開いているものだけに** を選んで書き、保存
5. **✨ 用語を抽出** →「人物・組織」「固有名・独自語」を選んで登録
6. **✨ 関係を下書き** で人物どうしの関係を引かせる

### 坊っちゃん（夏目漱石）— まず試すならこれ

[図書カード](https://www.aozora.gr.jp/cards/000148/card752.html)

```
語り手の「おれ」の口調で。江戸っ子の啖呵、短い断定、遠慮のない見立て。
自分のことは「おれ」と呼ぶ。
```

**登場人物がほぼ全員あだ名で呼ばれる**（赤シャツ、山嵐、狸、うらなり、野だいこ、
マドンナ）。あだ名と本名が併存するので、**別名**（同じ人物の別の呼び方を 1 つの
エントリにまとめる機能）がそのまま活きる。関係も分かりやすく、相関図がすぐ埋まる。

短いので、抽出も関係の下書きも待たされない。**最初の 1 本に向く。**

**この作品で実際に作った辞書が [samples/坊っちゃん](../samples/坊っちゃん/) にある。**
置いて開けばそのまま動くし、GitHub 上で
[赤シャツ.md](../samples/坊っちゃん/.glosspop/glossary/登場人物/赤シャツ.md)
を開けば、この口調で書かれた辞書の中身がそのまま読める。

### 吾輩は猫である（夏目漱石）— いちばん「らしい」

[図書カード](https://www.aozora.gr.jp/cards/000148/card789.html)

```
猫の語り手の口調で。「吾輩」と名乗り、人間を少し高いところから観察して評する。
漢語まじりの気取った言い回しに、皮肉をひとつまみ。断定しすぎない。
```

**猫が人間を観察して論評する話**なので、「猫が用語を解説する辞書」という枠組みが
作品の構造とそのまま噛み合う。無理に着せた口調にならない。

同じ人物が「主人」「苦沙弥先生」と呼び分けられるので、ここでも別名が要る。
32 万字あるので、**長い本文からの抽出**（全体から間引いて読ませる）や
**初出の場面だけ渡すネタバレ抑止**の効きも見える。

**この作品で実際に作った辞書が [samples/吾輩は猫である](../samples/吾輩は猫である/) にある。**
猫 3 + 人間 12 + 場所 2 で、カテゴリが「猫」と「人間」に分かれている。
[主人.md](../samples/吾輩は猫である/.glosspop/glossary/人間/主人.md) を開けば、
猫が飼い主を評した文がそのまま読める。

### 怪人二十面相（江戸川乱歩）— 予告状の調子で

[図書カード](https://www.aozora.gr.jp/cards/001779/card57228.html)

```
怪盗の予告状のように、もったいぶった芝居がかった調子で。読者に語りかける。
```

⚙ の例に入っている「怪盗の予告状風」がそのまま作品に噛み合う。明智小五郎・
小林少年・二十面相の関係と、変装や仕掛けの用語が並ぶ。乱歩は青空文庫に
[100 作以上ある](https://www.aozora.gr.jp/index_pages/person1779.html)ので、
気に入ったら同じフォルダに足していけばよい（**文体はフォルダに付く**ので、
足しても設定し直さずに済む）。

### 銀河鉄道の夜（宮沢賢治）— 落とさずに試せる

[図書カード](https://www.aozora.gr.jp/cards/000081/card456.html)（GlossPop の
`content\銀河鉄道の夜.txt` に同梱済み）

```
童話の語り口で。やわらかく、少し硬質な言葉づかい。理科の言葉をそのまま使う。
```

一人称の語り手はいないが、**賢治語**（ケンタウル祭、天気輪の柱、プリオシン海岸、
三角標）が辞書向き。展開のうえで伏せたい関係があるので、
[ネタバレを防ぐ](../MANUAL.md#ネタバレを防ぐ小説の人物辞書など)と組み合わせると分かりやすい。

## 小説以外

口調は「作家の真似」だけのものではない。**その資料を読む人の耳に馴染む書きぶり**を
指定するもので、実用の文書でも効く。

| 読むもの | 書いてみる指示 |
| --- | --- |
| TRPG のルールブック | 卓上でそのまま読み上げられる調子で。世界観の語り口を保ち、判定や数値は正確に書く。 |
| 社内資料・引き継ぎ | です・ます調。前提を知らない人が読む前提で、略語は必ず開く。 |
| 技術文書 | 短く言い切る。曖昧な修飾を避け、動作と制約を分けて書く。 |
| 医療・法務など硬い資料 | 常体で簡潔に。断定できないことは断定しない。 |
| 学習ノート | 中学生に説明するつもりで。難しい語は身近な例に言い換えてから使う。 |

## 気をつけること

- **ネタバレ設定のほうが強い。** 「結末をほのめかす調子で」と書いても、
  「初出の場面だけ」を選んでいれば AI に届くのは初出の場面だけ。
  読ませていないものは書けない（→ [ネタバレを防ぐ](../MANUAL.md#ネタバレを防ぐ小説の人物辞書など)）
- **途中で変えると口調が混ざる。** 前に作ったエントリはそのまま残る。気になる語は
  **編集 → ✨ AI で書き直す** で 1 語ずつ直せる（まとめて書き直す口は無い ——
  手で直した本文まで消えるため）
- **長い指示ほど効くとは限らない。** 400 字まで書けるが、要点は 1〜2 文で足りる。
  細かく縛るほど、AI は文体のほうに気を取られて中身が薄くなる
- **「〜風」は作風の指定であって、その作家の文章を持ってくるわけではない。**
  ただし出来たものを外に出すなら、誰それ風と名乗ることの是非は別に考えること
- 作品の本文そのものは、青空文庫にあるもの（著作権の切れたもの）を手元で読むぶんには自由
