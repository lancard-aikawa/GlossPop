# GlossPop へようこそ

このファイルは `content/` ディレクトリに置かれたサンプルです。左のパネルから開けます。

## 試しかた

本文中の知らない言葉を **マウスで選択** してみてください。選択したテキストの下に
「＋ 辞書に登録」ボタンが出ます。押すと登録ダイアログが開き、「✨ AI で下書き」で
Claude が定義・カテゴリ案を作ります。

保存すると、その語は以後 **本文中で自動的にリンク** になります。リンクにカーソルを
乗せると吹き出しが出て、クリックすると固定表示されます。吹き出しの中の
「辞書ページを開く →」から辞書ページに移動できます。

## 登録してみるとよい語の例

- イミュータブル な値を使うと、状態の追跡が楽になる。
- HTTP の `PUT` は冪等なので、リトライしても安全。
- この API は結果整合性を前提にしている。
- レンダリングのたびに仮想 DOM の差分を取る。
- サプライチェーン攻撃を避けるため、公開直後のパッケージは入れない。

## 同じ言葉が複数の意味を持つとき

用語は「カテゴリ + 用語名」で区別されるので、同じ表記を別々の意味で登録できます。

昼はソースを読んでバグを直し、夜はコロッケにソースをかけた。

この「ソース」にカーソルを乗せると、吹き出しがカテゴリごとのアコーディオンになり、
どちらの意味かを選んで読めます。

## 小説の登場人物を辞書にする

同じフォルダに `銀河鉄道の夜.txt`（青空文庫）を置いてあります。**Shift_JIS のまま、
ルビ付き**のファイルです。開いて「✨ 用語を抽出」を押すと登場人物や固有名詞が候補に出ます。

このとき **保存先を「このフォルダだけ」**にすると、その作品専用の辞書になります。
また **ネタバレ設定**を「初出の場面だけで書く」にしておくと、AI は初出の場面しか
読まないので、まだ読んでいない先の展開を書きません。

登録すると初出の位置が残り、辞書ページの「初出: 〜 →」からその場面に飛べます。

## URL を開く

左パネルの **URL を開く** に URL を入れると、その Web ページを取り込んで表示します。
本文だけを抜き出すので、ナビゲーションや広告は落ちます。

## リンクにならない場所

コードブロックの中は自動リンクの対象外です。

```python
# ここに書いた「イミュータブル」はリンクにならない
value = ("イミュータブル", "な", "tuple")
```

一方、インラインコードの `イミュータブル` はリンクになります。日本語の文書では
バッククォートを「コード」ではなく用語の強調として使うことが多いためです。

既にリンクが貼られている箇所も二重にリンクされません。

**冪**等 のように強調で語が分断されていても、まとめて 1 つのリンクになります。

## Claude Code から登録する

ブラウザを開かずに登録することもできます。

```
/gloss-add 結果整合性
```

登録先は `data/glossary/<slug>.md` です。エディタで直接開いて編集しても、
ブラウザを再読み込みすれば反映されます。
