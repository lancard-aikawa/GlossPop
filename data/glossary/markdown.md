Markdown は、見出し・箇条書き・強調・リンクなどの文書構造を、`#` や `*` といった簡単な記号だけで表現できる軽量マークアップ言語です。
プレーンテキストのまま読み書きでき、専用のレンダラーで HTML などの整形済み表示に変換できます。

README ファイルやドキュメント、ブログ記事、チャットツールのメッセージ整形など、幅広い場面で標準的に使われています。
GlossPop では、このような Markdown 形式のテキストをそのまま読み込んで表示し、本文中の語句を選択するだけで辞書登録できるビューアとして扱われています。
