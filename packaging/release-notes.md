Windows 版（Python のインストールは不要）。

## 使い方

1. `GlossPop-*-win-x64.zip` をダウンロードする
2. **展開する前に** zip を右クリック → プロパティ → 下部の「セキュリティ: 許可する」に
   チェック（`Unblock-File .\GlossPop-*.zip` でも可）。署名していないため、これをしないと
   起動時に SmartScreen の警告が出る
3. 好きな場所に展開して `GlossPop\glosspop.exe` を実行
4. 専用ウィンドウが自動で開く（開かないときはブラウザで http://127.0.0.1:8765/）
5. ファイル一覧の `ようこそ.md` を開く

ウィンドウを閉じてもサーバは止まらない。終わるときはコンソールも閉じること。

サンプルとして 3 語（`冪等` と、プログラミング / 料理で意味が違う `ソース`）が最初から
入っている。`ようこそ.md` の中で自動リンク・吹き出し・同表記の使い分けをそのまま試せる。
不要なら `data\glossary\` の中を消せばよい。

## できること

- **専用ウィンドウで開く** — タブもアドレスバーも無いアプリのような窓
  （中身は Edge。exe をダブルクリックするだけで開く）
- Markdown / テキスト / HTML / **epub** / **pdf** を開き、選んだ語をその場で辞書に登録
- **▶ 読み上げ** — 本文を音声で読む。読んでいる段落が色づき、速さと音声を選べる。
  聞きながら自動リンクと吹き出しがそのまま使える
- 登録した語は以後の表示で自動リンクになり、ホバーで吹き出しが出る
- **📁 フォルダを選ぶ…** で任意のフォルダを開く（最近開いた / お気に入りを記憶）。
  左パネルは **📁 フォルダ** と **🔗 URL** のタブで、**開いたものに合わせて切り替わる**
  ので、いま効いているのがどちらの辞書かが常に分かる。1 つだけのファイルと貼り付けは
  **＋ その他の開き方** の中（ドロップは今までどおりウィンドウのどこでも効く）
- **✨ 用語を抽出** — 表示中の文書やフォルダ全体から辞書化する語を AI に挙げさせ、
  選んだ語だけまとめて登録。**何を抜き出すか**（人物・組織 / 固有名・独自語 /
  専門用語・略語 / 鍵になる語）を先に選ぶので、登場人物と専門用語が枠を取り合わない
- **相関図** — 用語どうしの関係を図にする。誰と誰が、どちら向きに、どんな関係かを
  一言つきで持てる。関係は片側に書けば相手側にも出る。**判明位置**を書いておくと
  相関図では既定で伏せられる（図はネタバレ装置になりやすいので）。
  ビューアの **🕸 この文書の相関図** から開くと、**その文書に出てくる語だけ**に
  絞れる（どちらの図を見ているかは常に画面に出る）
- **見せ方が 5 つある**（図の左上で切り替え。選んだものは覚える）——
  **段の図**（既定。上下を段で表す）、**交差しない図**（関係 1 本ごとに独立した列を
  持つので線が交わらない）、**行列**（**まだ関係を書いていない組が空きマスで見える**）、
  **中心の図**（1 語を真ん中に置いて 2 つ先まで。辞書が大きくなっても絵の大きさが
  変わらない）、**時系列**（文書を開いているときだけ。**読み進めると関係が読める
  ようになる順**に並ぶ）。どれでも線やマスを押せばその関係を直せて、拡大縮小と
  移動もできる。乗せたものの説明は図の下の枠に全文で出る
- **画面が重なる** — 辞書・用語ページ・相関図・点検は**読んでいる本文の上に重なる**。
  閉じれば開いていた場所へ即座に戻る（本文を読み直さないので、長編でも待たない）
- **✨ 関係を下書き** — すでに登録した用語どうしの関係を、**表示中の文書**から
  AI に探させる（ビューアの本文の右上）。用語をまとめて登録したあと、そのまま
  続けて実行することもできる。書き込んだあとに **続けて探す** を押せば、
  書いたぶんを除いてもう一度探せる
- **文体（口調）を指定できる** — 「講談調で」「TRPG のルールブック風に」と書いておけば、
  AI の下書きがその調子になる（⚙ の **AI** タブ）。効くのは要約・本文・使用例と
  関係の一言だけで、用語名やカテゴリは崩れない。**作品ごとに置ける**ので
  （フォルダの `.glosspop` に入る）、小説と社内資料を行き来しても切り替え直さずに済む。
  そのフォルダぶんは**左パネルからも書ける**（⚙ を開かずに済む）
- **語り手の顔を置ける** — 文体と同じ場所の `persona.png` が、吹き出しと用語ページに
  丸く出る。**画面から選んで差し替えられる**（左パネルの「📁 いま読んでいるものの
  AI 設定」か ⚙ の **AI** タブ）。エクスプローラから直接置いても同じで、置き場所の
  パスは ⚙ に出ている
- **辞書の書き出し / 取り込み** — 全体の辞書を zip にできる（中身は Markdown のまま）。
  **1 カテゴリだけ**書き出して人に渡すこともできる（選んだ時点で「何語入るか」と
  「渡した先で行き先の無くなる関係が何本か」が出る）。取り込みは **置き換え** と
  **併合** から選ぶ。別の PC で書いた辞書を持ち込むなら併合（手元にしか無い用語は
  消えない）。**実行の前に「足す / 上書き / 消える」の件数が出て**、控えも自動で取る
- **控えの中を見て 1 件だけ戻せる** — 取り込みの前に自動で取った控えが一覧に並び、
  開けば入っている用語が出る。併合で上書きした用語はそこにしか残らないので、
  そこから 1 件だけ書き戻せる。**古いものを自動で消すことはしない**（合計の大きさが
  出るので、溜まったらその場で捨てる）
- **まとめる** — 「主人」と「苦沙弥先生」のように同じものが 2 つに割れてしまったとき、
  用語ページから 1 つにできる。まとめる側の呼び方は別名として残るので、本文では
  どちらの言い方でもリンクになる。実行の前に**何がどうなるかを全部見せる**
- **🩺 点検** — 辞書全体を見て、壊れた参照・要約や本文の抜けを挙げる。
  まだ書いていない相手はそのまま登録に入れるので「次に書くべき語の一覧」にもなる
- **⚙ 設定** — データの保存先（更新のたびのコピーを無くせる）、**使う AI**、表示
  （テーマ＝OS に合わせる / ライト / ダーク、**各用語の最初の 1 回だけリンク**）、
  更新の確認の切り替え
- **使う AI を選べる** — Claude Code CLI（既定・推奨。API キー不要）か Gemini API。
  **モデルと思考の深さ**も選べるので、速く済ませるか丁寧に書かせるかを決められる
  （変更は次の呼び出しから効く。再起動は要らない）
- **フォルダ辞書** — そのフォルダを開いている間だけ有効な辞書を持てる
  （小説の登場人物、現場固有の略語など。全体の辞書と混ざらない）。1 巻 2 巻を
  別フォルダにしていても、作品フォルダに 1 つ置けば共有される。**カテゴリの並び順や
  説明もフォルダ側で持てる**ので、小説なら 主要人物 → 脇役 の順に並べられる
  （「カテゴリ管理」の ↑ ↓。フォルダごとコピーすれば並びも付いてくる）
- **URL ごとの辞書** — 「ドメイン + パス」で範囲を決めた辞書。`docs.python.org/3/library`
  以下を読むときだけ効く、といった使い分けができる
- 保存先（全体 / このフォルダ・この URL）は**既定で AI が語ごとに選ぶ**。
  あとから辞書ページの **編集** で選び直せば、ファイルごと移動する（どちらの向きでも）
- **ネタバレ設定** — AI にどこまで読ませるか（初出位置だけ / 初出の場面だけ / 全文）を選べる。
  登録すると初出の位置（章・ページ・行）が残り、そこへ飛べる

同梱の `content\銀河鉄道の夜.txt` は青空文庫（宮沢賢治）のサンプル。Shift_JIS のまま
置いてあり、そのまま開いて登場人物の辞書を作れる。

`glosspop.exe` だけ取り出しても動かない。`_internal\` と同じフォルダに置いたまま使うこと。

辞書は exe と同じ場所の `data\glossary\` に保存される。書き込めない場所
（`Program Files` など）に置く場合は環境変数 `GLOSSPOP_GLOSSARY_DIR` で保存先を指定する。

## 更新するとき

新しい版が出ると、上部に小さく **`v0.9.0` が出ています** と出る（押すとリリース
ページが開く）。1 日に 1 回まで GitHub に聞くだけで、⚙ の「更新の確認」で切れる。
**アプリ自身が外へ通信するのは、ここと「AI に Gemini を選んだとき」の 2 つだけ。**

### アプリに持ってきてもらう（いちばん楽）

⚙ の **更新の確認 → ⬇ 新しい版を隣に展開する** で、zip を落として同じ階層に
`GlossPop-0.9.0` として展開する。あとはそちらの `glosspop.exe` を起動するだけ。

**いまのフォルダは触らない**ので、問題があればそのまま戻れる。動いている exe を
置き換えないので、昇格もウイルス対策ソフトの警告も起きない。

### 手で展開する

**上書き展開はしない**（`_internal\` に旧バージョンのファイルが残る）。新しいフォルダへ
展開して、旧フォルダから `data\` と `content\` をコピーする。

`data\` は**丸ごと**コピーすること。中の `data\window` にお気に入り・最近開いた
フォルダ・ネタバレ設定が入っているので、`data\glossary` だけコピーすると
辞書は無事なのに設定だけ消える。

### 次からコピーしなくて済むようにする

⚙ の **データの保存先 → 別の場所に置く** で、辞書などをアプリの外
（`ドキュメント\GlossPop` など）へ移せる。いまのデータの複製もその場でできる
（**元は消さない**ので、問題があれば戻せる）。

一度移しておけば、**次からの更新は新しいフォルダへ展開するだけ**で、コピーは要らない。
設定はアプリのフォルダの外（`%APPDATA%\GlossPop\settings.json`）にあるので、
アプリを入れ替えても残る。

持ち運び（USB など）を優先するなら、既定の「アプリの隣」のままでよい。

### 更新したら辞書が空になっていたら

**あわてて消さないこと。データは旧フォルダに残っている。** 新しいほうを起動すると
⚙ の先頭に「隣のフォルダにデータがあります」と出るので、**引き継ぐ**を押せば
持ってこられる（元は消さない）。

コマンドからでもできる。

```
glosspop migrate --from "C:\旧\GlossPop"
```

### 0.4.0 より前から上げるとき

古い辞書の `related`（関連語）は、読み込み時に新しい `relations`（関係）へ移される。
**0.3.0 以前に戻すとその関係は失われる**ので、しばらくは旧フォルダを残しておくこと。

## AI 下書きについて

下書き・抽出・関係の下書きに使う AI は ⚙ の **AI** タブで選べる。**変更は次の
呼び出しから効く**（再起動は要らない）。

**特に理由がなければ [Claude Code](https://claude.com/claude-code) を入れること。**
`claude` を入れて一度ログインすれば、**このアプリ側の設定は何も要らない**。
**exe には同梱していない**ので、別に入れる必要がある。

| | Claude Code CLI（既定・推奨） | Gemini API |
| --- | --- | --- |
| 準備 | `claude` を入れて一度ログインする | Google AI Studio で API キーを発行して ⚙ に貼る |
| API キー | **要らない**（CLI の認証を使う） | 要る |
| 費用 | Claude の契約に含まれる | API の従量課金（無料枠あり） |
| モデル | Haiku / Sonnet（既定）/ Opus | API から一覧を取得して選ぶ |

Gemini は API キーの発行という手順を踏める人向け。迷うなら Claude Code CLI にすること。

どちらも用意が無ければ、AI を使う機能だけが無効になる（手入力での登録はできる）。

**文体（口調）も指定できる。** 「講談調で」「史伝・評伝のような筆致で」
「TRPG のルールブック風に」と書いておけば、その調子で下書きされる（⚙ の **AI** タブ。
例を押せばそのまま入る）。効くのは**要約・本文・使用例と、関係の一言だけ** ——
用語名・カテゴリ・関係の相手は文体では崩れない（崩すと本文でリンクにならず、
関係も書き込めなくなるため）。

**語り手の顔も置ける。** 文体と同じ場所の `persona.png` が、吹き出しと用語ページに
丸く出る。**画面から選んで差し替えられる** —— 左パネルの「📁 いま読んでいるものの
AI 設定」か ⚙ の **AI** タブで **選ぶ… / 差し替え…** を押す（エクスプローラから直接
置いても同じで、置き場所のパスは ⚙ に出ている）。`.png` `.jpg` `.webp` `.gif` が
2 MB まで。**顔はその用語がどの辞書にあるかで決まる**ので、同じ表記が複数の辞書に
あるときは行ごとに違う顔が出る。

**口調は作品ごとに置ける。** 「全体に」か「📁 いま開いているものだけに」を選ぶ。
📁 のぶんは辞書と同じ `.glosspop` の中（`style.md`）に入るので、**フォルダごと
コピーすれば口調も一緒についてくる**し、作品フォルダに 1 つ置けば巻をまたいで効く。
どちらが効いているかは画面に出る（優先順は 環境変数 > 📁 > 全体）。

**モデルと思考の深さも選べる。** 深いほど丁寧になり、そのぶん時間がかかる
（所要時間は AI が考えた量にほぼ比例する）。速く数をこなしたいなら軽いモデルを選べば
よく、**こちらで選択を止めることはしない**。

**Gemini を選ぶと、下書きのたびに本文が Google へ送られる。** Claude Code CLI を
選んでいるときに通信するのは CLI 側で、このアプリ自身は外に出ない。
